PIXELHUB 3D UPGRADE

This is a single-file replacement homepage:
- index.html contains the PixelHub homepage, mini-game cards, and the 3D BlockWorld game.
- Replace your existing PixelHub/index.html with this index.html.
- Keep your existing style.css and script.js if you want, but this new index.html has its own CSS and JavaScript built in, so it does not need those files.
- Double-click index.html to open locally.
- Three.js loads from jsDelivr CDN. The website and non-3D mini-games still work if the CDN is blocked, but the 3D world requires that library to load.
- External links open official external sites and may be restricted by your network.
Controls in 3D: WASD / arrows, Space to jump.
